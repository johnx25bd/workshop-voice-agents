# Instructor materials

Planning and reference docs for delivering the Voice Agents workshop.

- **[NOTES.md](NOTES.md)** - Lecture notes covering voice agent architectures, audio tokenization, VAD, endpointing, and the model landscape
- **[PLAN.md](PLAN.md)** - Workshop execution plan with timeline, pacing notes, and contingencies
- **[OBJECTIVES.md](OBJECTIVES.md)** - Learning objectives per phase
- **[LOGISTICS.md](LOGISTICS.md)** - API key provisioning, setup, day-of checklists
- **[PRESENTATION.md](PRESENTATION.md)** - Slide deck outline and speaker guidance

These files are on the `instructor` branch only and not included in the student-facing `main` branch.
